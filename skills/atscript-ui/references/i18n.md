# i18n — built-in UI texts in the user's language

Every built-in component text (buttons, empty states, filter chips, `Yes`/`No`, workflow status messages) is a UI text with a `UI_*` code, English by default. Docs: https://ui.atscript.dev/guide/i18n

## Quick start

```vue
<!-- client root -->
<script setup lang="ts">
import { provideAsLocale } from "@atscript/vue-form";
provideAsLocale(
  () => locale.value,
  (id, params, locale) => (i18n.te(id) ? i18n.t(id, params ?? {}) : undefined), // optional
);
</script>
<template><RouterView :key="locale" /></template>
```

```ts
// translation source list / server registration
import { AS_UI_MESSAGES } from "@atscript/ui/messages"; // { UI_CANCEL: "Cancel", UI_FORM_ADD: "Add {item}", … }
```

## Rules

| #   | Rule                                                                                                                                                                                                                                                                                                                         |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Lookup: app `translate` (final text, no fill; `undefined` or the id itself = untranslated) → texts the server sent for the current locale → `AS_UI_MESSAGES` English → the id. `{name}` filled in one pass.                                                                                                                  |
| 2   | `@atscript/ui/messages` imports nothing (no Vue/DOM) — safe on a server. `AS_UI_MESSAGES` is NOT exported from the `@atscript/ui` root. Translate codes, keep placeholders.                                                                                                                                                  |
| 3   | Server texts: workflow forms (`inputRequired.payload.$i18n`); since 0.1.165 also tables, value help and action forms (see below). `@atscript/moost-wf` registers `VALIDATOR_MESSAGES` + `AS_UI_MESSAGES` on import; a table-only server calls `registerMessages(AS_UI_MESSAGES)` (moost) once itself.                        |
| 4   | Locale switch = remount (`<RouterView :key="locale">`). The meta cache (`getMetaEntry`) and table defs (boolean labels) are keyed per locale — switching back is instant; union variant names (`labelCode`) are worded at render time.                                                                                       |
| 5   | `provideAsLocale` is per app and SSR-safe: components pass its `t` into definition builders, so server HTML matches the client. In a browser it also serves code outside components (stacked per provider).                                                                                                                  |
| 6   | `setUiLocale(locale, translate?)` (`@atscript/ui`) = browser-global, for non-Vue apps only. Never on a multi-user server; don't combine with `provideAsLocale`.                                                                                                                                                              |
| 7   | Custom components: `const { t } = useAsLocale()` → `t("UI_CANCEL")`, `t("UI_FORM_ADD", { item })`. Never hard-code English that duplicates a code.                                                                                                                                                                           |
| 8   | `useWfForm` / `<AsWfForm>` send `Accept-Language` from the provider (unless `fetchOptions.headers` has one, any case — then `$i18n` is not merged) and merge `$i18n` into the locale the request was sent in.                                                                                                                |
| 9   | Optional `t` (default: active UI texts): `conditionLabel`, `filterTokenLabel`, `formatFilterExpr`, `temporalShortcuts`, `formatColumnCondition` `opts.t`, `resolveSystemPresets`, `createTableDef`, `resolveOptions`, `extract(Field)LiteralOptions`, `getMetaTableDef(entry, texts)`, `formatCellValue`, `queryTargetGate`. |
| 10  | `DEFAULT_BOOLEAN_LABELS` / `QUERY_TARGET_UNSUPPORTED_REASON` stay English constants; the UI shows `UI_YES`/`UI_NO` / `UI_ACTION_QUERY_UNSUPPORTED` in the locale. Branch on codes, never on text.                                                                                                                            |
| 11  | `translate` gets real params (`count`), so it can apply plural rules; English uses `_ONE` / plural code pairs.                                                                                                                                                                                                               |
| 12  | Tables / value help (0.1.165): the `ClientFactory` gets the app's `locale` (`ClientFactoryOptions.locale`, sent as `Accept-Language`). A custom factory MUST spread `options` into `new Client`; a factory caching clients keys them by URL **and** locale.                                                                  |
| 13  | Client-side validation messages (0.1.165): `getFormValidator` / `createFieldValidator` / `<AsForm>` word errors by code (`MIN_LENGTH` + params) through the app's `t`: `translate` → served `$i18n` → English. db-client write errors (preflight, `400`) are already in the client's locale.                                 |

### Tables, value help and action forms (0.1.165, `@atscript/moost-db` ≥ 0.1.170)

- `/meta` `type.$i18n` (tables, value help) and an action form's own `$i18n` (db-client `getActionFormTexts(name)`, merged when its dialog opens) are merged into the app's texts for the locale.
- `getMetaEntry(url, f, { texts })` / `resolveValueHelp(url, { texts })` take the app's texts (default: the active ones); components pass theirs.
- SSR-safe, no module state per locale: on a server the process-global texts ignore merges, so an app without `provideAsLocale` renders built-in texts in English.
- Action-form dialogs merge only under `TableContext.locale` (the table client's), and only while the app still shows it.

## Server side (moost + `@atscript/moost-wf`, since 0.1.165)

`setTranslator({ en: {}, de: {…} })` (moost) is all a workflow server needs. Docs: https://ui.atscript.dev/guide/i18n-server

| #   | Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1  | Served per request locale: form schema texts (`@meta.*`, constraint messages, `@ui.*` texts: placeholder, hint, options label, submit.text, label.singular, action label, prefix/suffix, literalLabel label, nav.group, array add/remove label), validation errors (by code, params filled, before the error map), `requireInput` `errors`/`formMessage` and `finishWf`/`abortWf` `message.text`, button labels, `skipButton.label` (by text; the abort `reason` is a machine slug, never translated). Pass source texts — never pre-translate. |
| S2  | Never translated: workflow state/context, `data`, abort `reason`, `@ui.form.attr` values, classes/styles, option values (an option without a value gets its source label as value at compile time).                                                                                                                                                                                                                                                                                                                                             |
| S3  | Schema memoized per (form type, locale) for the translator's locales; without a translator the same untranslated object as before. Opt out per form: `serializeFormSchema(T, { translate: false })`, `useAtscriptWf(T, { translate: false })`, `@WfInput({ translate: false })`, `@WfAction(T, { translate: false })`.                                                                                                                                                                                                                          |
| S4  | `$i18n` on the schema = registered templates translated (only those differing from English) + translated string literals of text expressions. Everything passed to `registerMessages` is PUBLIC (served in every `$i18n`).                                                                                                                                                                                                                                                                                                                      |
| S5  | Expressions: called as `(v, data, ctx, entry, t)` / `(data, ctx, t)`; `t(text, params?)` → served translation by exact match, else `text`, `{name}` filled. Text results (`fn.label/description/hint/placeholder/title/submit.text`, option labels, `@ui.form.validate` messages) that exactly match a served text show translated. Write whole literals: `t("Hello {name}", { name })`, never `"Hello " + name`.                                                                                                                               |
